# Six public workflow replays

These are edited replays of real CLI logs, not original screen captures.
The four-second cards are editorial pacing, never measured latency.
[Source run and asset hashes](MANIFEST.txt) · [Static view](STATIC.md) · [Media rights](../RIGHTS.md)

No private application or invented benchmark is shown. Placeholders such as SAVED_SHA256
abbreviate command display only; the exact executed arguments are in each transcript.
Commands shown after gel-evidence are its stdin, not unsupported command-line subcommands.
Expected failure cases have checked nonzero exits. Full human visual acceptance remains open.
